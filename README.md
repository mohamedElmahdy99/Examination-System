🏫 ITI Examination System
A comprehensive web-based Examination Management System for ITI institutions, developed using ASP.NET Core MVC and SQL Server. This system streamlines and automates student management, exam generation, role-based access, department and staff management, and more — tailored to meet the academic and administrative needs of Industrial Training Institutes (ITI).

🔑 Key Features
🎓 Student & User Management
Register and manage student profiles across multiple branches.

Assign students to departments, courses, and instructors.

Role-based access control for:

Admins (global settings and full control)

Branch Managers (control over their specific branch)

Instructors (course and exam management)

Students (profile and exam access)

🏢 Branch & Department Management
Manage multiple ITI branches within the system.

Create and organize Departments under each branch.

Hire and assign staff to specific departments.

Department-wise user and data segregation.

📝 Exam Generation & Question Bank
Create and manage examinations with various question types (e.g., MCQs, True/False, Descriptive).

Organize and maintain Question Banks per branch and department.

Random or custom selection of questions for exam generation.

📊 Results & Grading
Track and manage student exam grades and results.

Support for performance evaluation and statistics.

Exportable reports and grading summaries.

📄 Reporting System
Generate role-based reports for Admins, Branch Managers, and Instructors.

Custom filters for departments, branches, students, or courses.

Export reports for offline analysis (Excel, PDF).

🛠️ Tech Stack
Backend: ASP.NET Core MVC

Database: Microsoft SQL Server

Frontend: Razor Views, HTML5, CSS3, Bootstrap

Authentication: ASP.NET Identity (Role-based access)

ORM: Entity Framework Cor
